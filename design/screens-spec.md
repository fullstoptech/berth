# Berth screens spec (for the Screens page)

Built from Components instances only, real data from `design/mocks/berth.json`, frames named `<Screen> / <state> / <width>`. Window 1440x900 unless noted. Shell (brief 7.1): TitleBar 38 · Sidebar 220 · main · Inspector 360 (when an item is selected) · bottom panel (when open, 280 tall, tabs Logs / Terminal / Problems (n) / Assistant). One focal point per screen; one primary action per context.

Shared rules: status is the only colour; row actions visible on hover and on the selected row; numbers right-aligned tabular; every active filter shown as a chip with ×; a status bar line at the very bottom of the window (22px, muted caption): engine `colima/default · Docker 28.4.0 · 4 CPU · 8 GB · 14 running`, plus Problems count on the right.
